## Visão Geral

Este repositório contém o código-fonte do portfólio pessoal e profissional de **Henrique Bering**. Desenvolvido com foco em estética corporativa, elegância, performance e total responsividade (mobile, tablet e desktop), servindo como hub para apresentação de projetos práticos e contato profissional.

### Destaques
- **Design Clean & Corporativo:** Tipografia refinada (fonte Inter), paleta de cores corporativa e hierarquia visual bem estruturada.
- **Responsividade Total:** Adaptado para diferentes resoluções e telas através de Media Queries, CSS Grid e Flexbox.
- **Interatividade & Animações:** Efeito de *scroll reveal* com `IntersectionObserver`, menu lateral para dispositivos móveis, navegação suave e detecção automática de seção ativa no menu.
- **Leve & Rápido:** Sem dependências ou frameworks pesados, garantindo carregamento instantâneo.

## Tecnologias Utilizadas

### Front-end do Hub
- **HTML5:** Marcação semântica e acessível (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3:** Variáveis CSS customizadas, animações, transições suaves, CSS Grid e Flexbox.
- **JavaScript (ES6+):** Manipulação de DOM, Intersection Observer API e controle de eventos de rolagem e menu.

### Stack Técnica em Destaque no Portfólio
- **Linguagens & Análise:** Python, SQL, Pandas, NumPy, Programação Orientada a Objetos (POO).
- **Plataformas & BI:** Databricks, Streamlit, Power BI, Excel.
- **Controle de Versão & Colaboração:** Git, GitHub.
